# ServiLocal API

Backend NestJS para la plataforma ServiLocal.

## Tecnologías
- NestJS
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Redis (rate limiting & cache)

## Scripts
- `pnpm start:dev`: Modo desarrollo
- `pnpm build`: Compilar para producción
- `pnpm test`: Ejecutar tests
- `pnpm prisma:migrate`: Aplicar migraciones
- `pnpm prisma:seed`: Cargar datos iniciales
